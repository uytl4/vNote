    đáp án) → có thể sai vài câu; sửa được ở 🔑.
  • ETS 2023 — 10 đề + sách RC. Đáp án Reading chép từ ảnh đáp án trong Drive.

TÍNH NĂNG
  • Full Reading (75'), Part 5, Part 6, Part 7; đặt thời gian tuỳ ý; hết giờ tự nộp.
  • Phím tắt máy tính: A–D chọn đáp án, ↑/↓ chuyển câu, F đánh dấu.
  • Điện thoại: thanh A B C D ở đáy màn hình cho câu hiện tại, ☰ mở cả phiếu trả lời.
  • Tự lưu bài, thoát ra làm tiếp được. Chấm điểm, tỉ lệ đúng từng Part, điểm ước tính,
    xem lại câu sai / bỏ trống / đã đánh dấu.
  • 🔑 Đáp án: dán, gõ, hoặc "📄 Từ file" (.txt/.csv/.json) — không cần mạng.
  • ⬇ Sao lưu / ⬆ Khôi phục: chuyển đáp án + lịch sử sang máy khác (file .json).

1) BỘ ĐỀ OFFLINE — KHÔNG DÙNG GOOGLE DRIVE
-------------------------------------------------------
  Web chạy hoàn toàn trên máy: đáp án có sẵn, đề lấy từ file PDF trên máy.
  Không tự lấy đề từ Google Drive (Drive chỉ là nút tuỳ chọn "Mở bằng Google Drive").

  Thiết lập 1 lần:
  1. Giải nén, nhấp đúp index.html (Chrome / Edge / Firefox / Safari).
  2. Có sẵn các file PDF đề trên máy (tải từ Drive bằng mạng khác / điện thoại,
     GIỮ NGUYÊN TÊN FILE gốc, ví dụ "TEST 1 RC (1).pdf", "ETS 2022 Test 3.pdf").
  3. Bấm "📁 Gắn PDF từ máy", chọn TẤT CẢ file PDF → web tự nhận file nào của đề nào
     và lưu trong trình duyệt. File không nhận ra: dùng "📎 Gắn PDF" ở đúng đề.
  4. Bấm "📦 Xuất gói đề" → được goi-de.zip. Giải nén vào CÙNG THƯ MỤC với index.html
     (sẽ có thư mục goi-de/ nằm cạnh index.html).

  Sau bước 4, thư mục web này là một BỘ ĐỀ OFFLINE HOÀN CHỈNH (đề + đáp án):
  chép sang máy khác, USB, hay đưa lên web đều mở được ngay, không cần mạng,
  không cần gắn lại. Đề có nhãn "📦 Có trong gói đề" / "📱 PDF trên máy" là làm được.
  Lưu ý: gói đề chứa nội dung đề ETS (có bản quyền) — chỉ dùng cho việc tự học của
  bạn, đừng đăng công khai.

2) IPHONE / IPAD
-------------------------------------------------------
  iPhone không chạy được web từ file index.html trong ứng dụng Tệp. Cách làm:
  đưa phần CODE lên GitHub Pages (miễn phí, không chứa đề), rồi nạp đề từ máy bạn.

  A. Bật GitHub Pages (làm 1 lần, trên máy tính):
     github.com/uytl4/vNote → Settings → Pages → Source: "Deploy from a branch"
     → Branch: claude/youthful-clarke-3zbkva, thư mục "/ (root)" → Save.
     Đợi 1–2 phút, địa chỉ app:  https://uytl4.github.io/vNote/toeic-web/
     (Bản trên mạng KHÔNG có thư mục goi-de/ — nội dung đề không bị công khai.)

  B. Chép 30 file đề .md vào iPhone (iCloud Drive / AirDrop / cáp) → ứng dụng Tệp.

  C. Trên iPhone (khi có mạng):
     1. Mở Safari → vào địa chỉ ở bước A.
     2. Nút Chia sẻ (ô vuông mũi tên lên) → "Thêm vào MH chính" → Thêm.
     3. Mở app "TOEIC RC" vừa có trên màn hình chính (KHÔNG làm tiếp trong Safari —
        dữ liệu của app và của Safari tách riêng).
     4. Bấm "📁 Gắn đề từ máy" → Duyệt → chọn thư mục chứa file .md → Chọn → chọn
        hết 30 file → Mở. Web tự nhận đề nào của file nào và lưu trong máy.
     Xong: từ giờ mở app khi không có mạng vẫn làm bài được (đề + đáp án đều offline).
     Có thể gắn file PDF thay cho .md theo cùng cách.

  Lưu ý: xoá app khỏi màn hình chính sẽ xoá luôn đề đã gắn và lịch sử làm bài —
  nhớ "⬇ Sao lưu" trước (bản sao lưu gồm đáp án + lịch sử, không gồm file đề).
